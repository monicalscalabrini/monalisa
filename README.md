# Monalisa AI

Plataforma web desenvolvida para análise, refinamento e humanização de textos utilizando inteligência artificial.

## Funcionalidades

- Geração de resumos
- Humanização de textos
- Análise de naturalidade
- Análise de qualidade textual
- Upload de arquivos .txt, .pdf e .docx
- Interface responsiva

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Node.js
- Express
- OpenAI API

## Observações

O backend utiliza integração com API da OpenAI através de variáveis de ambiente locais.

Por segurança, o arquivo `.env` não está disponível neste repositório.

Para executar localmente:

```bash
npm install
node server.js
```

## Status

Versão acadêmica e experimental para fins de estudo e portfólio.
